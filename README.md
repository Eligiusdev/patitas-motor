# Historial clínico de Lola

Ejercicio de nodos enlazados manualmente en JavaScript. Cada nodo contiene una atención clínica y una referencia al siguiente nodo.

## Ejecutar

Desde la raíz del proyecto:

```bash
node pruebas/nodos.js
```

El programa recorre las tres atenciones en orden cronológico y luego suma sus costos. El total esperado es **$275.000**.
